# PeerLink

一个基于 `WebRTC` 的 `Minecraft` 联机模组。

此功能是从 `Minecraft` 快照版本 `26.2-snapshot7` 中分支（fork）出来的，目前该功能在官方版本中已被移除。

# 实现细节

PeerLink 使用专属的信令服务器来与其他 PeerLink 客户端进行通信。

创建一个房间以获取房间 ID，将其分享给你的好友，他们即可使用该房间 ID 加入你的世界。

## NAT 穿透

在 NAT 条件允许时，将直接使用 P2P 连接以绕过中间服务器。对于受限的网络环境，则会通过 TURN 服务器进行中继，以确保成功建立连接。

## 信令服务器

可用的公共信令服务器：

| 地址                              | 备注                 | TURN 服务器位置                      | 提供者                                        |
|-----------------------------------|----------------------|--------------------------------------|-----------------------------------------------|
| wss://peer.7o.ink                 | 内置的默认信令服务器 | 中国大陆                             | [xiaoman1221](https://github.com/xiaoman1221) |
| wss://peerlink-signaling.rtast.cn | 供全球用户使用       | Cloudflare（面向全球，中国大陆除外） | [RTAkland](https://github.com/RTAkland)       |

## TURN 服务器

可用的 STUN/TURN 服务器：

1. Cloudflare STUN/TURN
2. 由信令服务器分配的中国大陆 STUN/TURN 服务器
